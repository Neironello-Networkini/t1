# Handwritten Text Recognition Service

Сервис для распознавания рукописного и печатного текста на фотографиях. Создан в рамках рамках решения кейса от компании "Т1" в лагере Математического Моделирования МАИ 2025 г.

## Как это работает

Проект реализует пайплайн распознавания текста из изображения. 

![[images/3333.png]]

**Препроцессинг**
Немного увеличивает резкость фото (шарпенинг) для улучшения работы детектора. Отправляет детектору фотографию в формате BytesIO.

**Детектор (EasyOCR + CRAFT)**
Из POST-запроса через препроцессинг получает улучшенную фотографию в формате BytesIO. Определяет области с текстом, вырезает их по прямоугольному контуру (создаёт кроп) и помещает их во временную папку, предварительно её создав. Также к каждому кропу прилагаются метаданные в JSON файле с полями id, text, coordinates. 

**Классификатор (YOLOv8n)**
Принимает JSON и классифицирует кропы по свойству "рукописный, не рукописный", добавляя к соответствующему объекту в JSON флаг `handwrited: 1` (рукописный) или `0` (печатный).

**Модели распознавания (TrOCR)   - Получает JSON со списком кропов и флагами.
- Распознаёт текст на кропах, и записывает в соответствующий объект в JSON, в поле text, результаты распознавания.
- Передаёт JSON файл фронтенду.

**Выходной результат**
   - JSON-файл со списком кропов и распознанным текстом.
   - Исходное изображение с разметкой областей рукописного и печатного текста цветом разными цветами.
   - ![[images/image_2025-05-01_11-51-07.png]]
## Технологии

- Python 3.8+
- [EasyOCR (CRAFT)](https://github.com/JaidedAI/EasyOCR)
- [YOLOv8n (fine-tuned on handwritten texts)](https://huggingface.co/armvectores/yolov8n_handwritten_text_detection)
- [Hugging Face TrOCR-ru (fine-tuned on Cyrillic Handwritting Dataset)](https://huggingface.co/kazars24/trocr-base-handwritten-ru)
- FastAPI / Flask (REST API)
